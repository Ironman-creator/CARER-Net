# Reported numerical outputs

These directories contain the CSV and JSON artifacts used to audit the manuscript tables and analyses:

- `carer_3datasets/`: DRIVE, STARE, and CHASE_DB1 confirmation experiments.
- `fives_ablation/`: compute-matched module ablation.
- `fives_multiseed_validation/`: validation-stage decision artifacts.
- `fives_official_test/`: frozen official FIVES test evaluation.
- `fives_structural/`: disease/quality strata and vascular-structure measurements.
- `protocol_baselines/`: unified-protocol comparison models.
- `external_validation/`: zero-shot cross-dataset evaluation and calibration audit.
- `robustness/`: fixed perturbation evaluation.
- `efficiency/`: parameter, MAC, memory, latency, and throughput measurements.

The outputs are preserved as generated. Per-image files contain public dataset sample identifiers and numerical metrics, not fundus images, masks, patient identifiers, or model weights.
